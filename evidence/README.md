# Evidencias de la práctica SQA

- `manual/`: capturas del smoke test y registro de ejecución manual.
- `cypress/`: capturas y videos de los escenarios E2E, generados por Cypress.
- GitHub Actions conserva estos reportes como artifacts por 14 días; entra a **Actions**, abre la ejecución verde y descarga `evidencias-qa`.
- No incluyas contraseñas ni datos de contacto de funcionarios en capturas si no son necesarios para demostrar el caso.
